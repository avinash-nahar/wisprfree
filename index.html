How it works

Three seconds from thought to text

No server, no middleman app. The audio goes straight from your mic to Gemini and back.

1

Hold Right Shift

The floating Siri-style orb pulses to life at the bottom of your screen. A hardware-level keyboard listener picks up the key — zero UI lag.

2

Speak

Audio streams into a 16 kHz mono buffer. The orb's animation speed reacts to your mic volume in real time.

3

Release — transcription begins

The WAV chunk ships to gemini-3.5-transcribe. A green pulse on the orb shows processing state.

4

Text appears in your app

Result goes into your clipboard via pbcopy, then a hardware Cmd+V event pastes it — works in any app, even those that block normal paste.

Features

Built small on purpose. The best code is no code.

🎙️

Push-to-talk

Right Shift triggers recording. No UI to open, no mode to toggle.

🫧

Lottie orb HUD

Transparent floating window that disappears when idle. Alpha-stripped Siri animation, no black box.

⚡

Hardware paste

Uses Quartz CGEvent to fire a real Cmd+V — not a clipboard race condition.

💸

Gemini free tier

Runs on Google's free API quota. No credit card required to start.

🔒

Local-first

Audio is sent directly to Gemini. Nothing touches a third-party server.

🎓

Exam Mode

Say "exam mode on" — screenshot + Gemini Vision reads answers aloud. Completely stealth, no HUD.

Get started

Running in under two minutes

Requires Python 3.11+, a free Google AI Studio key, and macOS accessibility permissions.

$git clone https://github.com/avinash-nahar/wisprfree && cd wisprfree
$pip install -r requirements.txt
$echo "GEMINI_API_KEY=your_key_here" > .env
$python wispr_avi_hud.py
